# Como contribuir com o Que Bicho É Esse?

Todas as mudanças passam pela aprovação do @kevynbizerra37-hue antes de entrar no jogo.

1. Atualize sua cópia: `git checkout main && git pull`
2. Crie uma branch para a sua mudança: `git checkout -b minha-mudanca`
3. Faça as alterações e salve: `git add . && git commit -m "Descreva o que mudou"`
4. Envie a branch: `git push -u origin minha-mudanca`
5. No GitHub, abra um **Pull Request** da sua branch para a `main`.
6. Aguarde a revisão. Se pedirem ajustes, faça novos commits na mesma branch.

Ninguém consegue enviar direto para a `main`: o Pull Request só pode ser mesclado depois de aprovado.
